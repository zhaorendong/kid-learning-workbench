# 模块接入规范

> 这份文档是给"生成新学习内容"的人（或 AI）看的。
> 遵循它，新生成的 HTML 就能**自动出现在工作台里**，并自动记录学习数据。
> 框架本身不需要改动。

**先搞清楚边界**：工作台分成两个互不相干的页面 ——

| 页面 | 文件 | 谁维护 |
|---|---|---|
| 孩子端 | `index.html` + `assets/student.js` | 学习内容的入口，新模块只跟这一侧打交道 |
| 家长端 | `parent.html` + `assets/parent.js` | 带密码门禁，**生成内容时完全不用碰** |
| 共用 | `assets/core.js`（数据层）、`assets/catalog.js`（注册表）、`assets/xyb-sdk.js`（SDK） | 新增内容时只改 `catalog.js` |

新模块与工作台之间**只有一个接口**：`xyb-sdk.js` 写 localStorage 队列。
所以模块不需要知道家长端存在，家长端也不需要知道有哪些模块。

---

## 一、三步接入

```bash
# 1. 生成模块骨架（自动建目录 + 复制模板 + 写入注册表）
cd "D:\workspaces\WorkBuddy\小悦饼知识库"
python _build/new_module.py --id pinyin-1 --title "拼音王国" --subtitle "声母韵母 · 拼读听音" \
       --subject 语文 --type lesson --emoji "🅿️" --minutes 15 --path "识字与拼音" \
       --tags "拼音,听音辨字" --desc "点读发音 + 听音选字母 + 拼读连线。"

# 2. 编辑 modules/pinyin-1/index.html，把内容替换成真正的教学/练习内容

# 3. 体检 + 刷新工作台
python _build/new_module.py --check
```

如果是**已有**的独立 HTML（例如之前生成的数独教程），只需：

1. 把文件放进 `modules/<id>/index.html`（或保留原位）；
2. 在 `assets/catalog.js` 的 `modules: [` 后加一条（参照已有条目）；
3. 或用 `--register`：在模块目录放一个 `module.json` 后执行
   `python _build/new_module.py --register modules/<id>`。

## 二、目录约定

```
modules/
└── pinyin-1/
    ├── index.html      ← 入口（必须是这个名字）
    ├── module.json     ← 元信息（供脚手架读取，可选但推荐）
    └── assets/         ← 模块自己的图片/音频（可选）
```

- 资源一律用**相对路径**（`../../assets/xyb-sdk.js`、`./assets/a.png`）
- **不允许**引用外部 CDN（家里断网也要能用）
- **不允许**用构建工具，产物必须是能直接打开的静态文件

## 三、接入 SDK（关键）

在 `</body>` 前加一行：

```html
<script src="../../assets/xyb-sdk.js" data-module-id="pinyin-1" data-back="1"></script>
```

| 属性 | 必填 | 说明 |
|---|---|---|
| `data-module-id` | ✅ | 必须与 `catalog.js` 里的 `id` 完全一致，否则进度记到别处 |
| `data-back` | 建议 | `1` = 自动在右下角注入"🏠 返回学习台"悬浮按钮 |
| `data-auto` | 可选 | 例如 `30`，停留满 30 分钟自动计完成（防止孩子忘记点） |

### 可用 API

```js
XYB.progress(已做题数, 总题数)      // 更新完成度，卡片上会显示进度条

XYB.answer(true)                   // 这题答对 → 计入正确率
XYB.answer(false, '进位加法')       // 答错，只带知识点标签（老写法，仍兼容）

XYB.answer(false, {                // ★ 推荐：带上题干 → 自动进工作台"错题本"
  tag: '进位加法',                 //   知识点标签（家长端薄弱点分析用）
  q: '8 + 7 = ?',                  //   题干原文（错题本里显示的就是它）
  answer: 15,                      //   正确答案
  my: 16                           //   孩子写的答案
})

XYB.finish({ stars: 3 })           // 整份内容学完 → 工作台加星星 + 家长端记完成
XYB.speak('爸爸')                  // 朗读一段文字（浏览器自带语音合成，不需联网）
XYB.canSpeak()                     // 返回布尔值，据此决定要不要显示"听一听"按钮
XYB.exit()                         // 返回工作台
XYB.setting('soundOn', true)       // 读取家长端的设置（如音效开关）
XYB.stat()                         // 取本次 {asked, right}
```

> **错题本怎么工作的**：只有 `answer(false, {...})` 带了 `q`（题干）时才会入库，
> 所以老模块不改也不会误记。同一道题再错只累加次数、不重复占位；
> 孩子端打勾"我想出来了"就移出待订正列表，家长端能看到完整台账。

> **朗读的注意事项**：`XYB.speak()` 用的是系统自带的语音合成，读**汉字**是准的，
> 读单个字母（如 "b"）反而不准 —— 拼音类内容建议读示例词（读"爸爸"而不是读"b"）。
> 家长端关掉"音效与语音"后 `XYB.speak()` 会自动静默。浏览器不支持时静默跳过，不会报错。

### 上报时机建议

| 场景 | 调用 |
|---|---|
| 页面加载完 | 不用管，SDK 自己报 `ready` |
| 每答一题 | `XYB.answer(对错, { tag, q, answer, my })` |
| 每完成一关/一批 | `XYB.progress(完成数, 总数)` |
| 全部完成 | `XYB.finish({ stars })` |
| 用户点退出 | `XYB.exit()`（`data-back` 会自动加按钮，不必自己写） |

`stars` 建议：正确率 ≥90% → 3；≥70% → 2；其余 → 1。

### 没有接入 SDK 的内容怎么办

在 `catalog.js` 里把 `progress` 设为 `'manual'`，卡片底部会出现"标记为已学完"按钮，由家长手动打勾。
适合可打印材料、线下活动、视频等无法上报的内容。

## 四、注册表字段说明（`assets/catalog.js`）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一标识，小写英文+连字符，与 `data-module-id` 一致 |
| `title` | ✅ | 卡片标题 |
| `subtitle` | | 一句话副标题 |
| `subject` | ✅ | 语文 / 数学 / 英语 / 思维 / 科学 / 艺术 / 综合（决定筛选归类） |
| `grade` | | 年级标签，如"一年级" |
| `type` | ✅ | `lesson` 讲解 / `practice` 练习 / `game` 游戏 / `print` 可打印 / `book` 读物 / `tool` 工具 / `video` 视频 |
| `tags` | | 最多显示 2 个，写在数组里 |
| `url` | ✅ | 相对路径，如 `./modules/pinyin-1/index.html` |
| `emoji` | ✅ | 封面图标，一个 emoji |
| `color` | ✅ | 主题色 HEX，建议按学科取色（语文蓝 / 数学橙 / 英语绿 / 思维紫…） |
| `minutes` | | 预计时长（分钟），显示在卡片上 |
| `desc` | | 卡片描述，1-2 句，建议写清"能学到什么" |
| `mode` | | `jump` 整页打开（默认） / `embed` iframe 内嵌 |
| `progress` | | `sdk` 自动上报 / `manual` 手动打勾 / `none` 不跟踪 |
| `featured` | | `true` 会出现在首页"推荐给你" |
| `path` | | 学习路径分组名，同组的会排成一条闯关地图 |
| `pathOrder` | | 组内顺序，从 1 开始 |
| `status` | ✅ | `ready` 已上线 / `planned` 规划中（显示为占位卡，点击提示"准备中"） |
| `extra` | | 附加资源，如 `[{ label:'可打印题库', url:'./xxx.docx', emoji:'🖨️' }]` |

```

语文 #3b82f6  数学 #f59e0b  英语 #10b981  思维 #7c6cf5
```

模块页面建议：

- 单独一个内容也可以有自己的**主题色**（如口算用橙色系），但要沿用同一套圆角与阴影语言
- 顶部用一个渐变 header + 圆角下沿，与工作台呼应
- 正文字号 ≥ 17px，按钮最小高度 ≥ 44px（儿童触控）
- 反馈文案温柔：答错写"再看看"，不要写"错了""不合格"

## 七、常见问题

**Q：学完之后工作台没有加星星？**
A：检查三处 —— ① `data-module-id` 是否与 `id` 一致；② 是否调用了 `XYB.finish()`；
③ 是否在 `file://` 下打开且浏览器隔离了跨目录 localStorage（换本地 HTTP 服务即解决）。

**Q：答错的题没进错题本？**
A：错题本要求 `q`（题干）非空，只传标签不会入库。另外同一道题重复错只累加次数，
想验证就去孩子端"🔁 错题本"页看有没有那张卡。

**Q：朗读没声音？**
A：① 家长端是否关掉了"音效与语音"；② 系统是否静音；③ `XYB.canSpeak()` 是否为 `false`
（那就换成"请孩子自己读出来"的文案，别硬做音频文件）。

**Q：我想让内容内嵌在工作台里（保留底部导航）？**
A：把 `catalog.js` 里该条目的 `mode` 改成 `'embed'`。内嵌模式下 SDK 会用 `postMessage`
实时通知父页面，无需刷新。

**Q：一个模块想拆成好几节（如拼音分 5 课）？**
A：两种做法：① 在模块内部做章节切换，只上报 `XYB.progress(节数, 总节数)`；
② 拆成多个模块，各自一条 `catalog.js` 记录，用同一个 `path` 串成闯关路径。
推荐 ②，进度更清楚。

**Q：模块可以碰家长端的东西吗？**
A：不可以，也不必要。家长端在独立的 `parent.html`，模块只通过 `xyb-sdk.js` 单向写
localStorage 队列，工作台下次打开时消费。模块里不要读写 `xyb.v1.guard`，
也不要尝试跳 `parent.html`。
