# 用户手册

> 给**孩子**和**家长**看的说明书。技术细节在 `开发手册.md` / `运维手册.md`，这里不涉及。

# 一、孩子端（给孩子用）

## 1.1 怎么打开

| 方式 | 怎么做 |
|---|---|
| 扫码 | 用平板相机扫家长给的二维码 |
| 输地址 | 浏览器地址栏输入 `http://<家里那台机器的地址>:8099/` |
| 添加到主屏 | Safari → 分享 → **添加到主屏幕**，之后点图标就能全屏打开，像 App 一样 |

> 孩子端**不需要登录、不需要密码**，打开就能用。

## 1.2 首页有什么

从上往下依次是：

1. **📌 今天的作业** —— 只显示**还没做完**的，做完就从卡上消失。点一下即打勾
2. **今日目标环** —— 今天要完成几个内容，进度一圈一圈填满
3. **▶ 继续学** —— 一键回到上次学到一半的内容
4. **内容卡片** —— 每个可以学的知识模块，卡片上有封面、学科、预计时长和得到的星星

## 1.3 底部五个 Tab

| Tab | 里面是什么 |
|---|---|
| 🏠 首页 | 作业卡 + 今日目标 + 推荐内容 |
| 📚 课程 | 全部内容墙、按学科筛选、搜索、学习路径闯关图 |
| 📝 错题本 | 做错的题都在这儿，可以看答案、标记"我想出来了" |
| 🏆 成就 | 12 个徽章，点亮了就是亮的 |
| 📌 作业 | 今天和以前几天的作业，最新一天完整展开 |

## 1.4 作业怎么打勾

- 首页作业卡上点一下 = 打勾（再点一下 = 取消）
- 全部做完会有彩带动画 🎉
- 有些条目是**给爸爸妈妈的**（比如"疫苗要提前说""在帽子上写名字"），
  孩子端只会显示一句"还有 N 件要提醒爸爸妈妈"，具体内容在家长端

## 1.5 星星和徽章

- 完成一个内容 **+3⭐**（有些内容自己定星级）
- 同一个内容重复学**不会重复加星**
- 12 个徽章：启蒙之星、小学者、博学小达人、专注力、深度思考、坚持三天、
  自律之星、闪闪发光、神算子、探索者、错题克星、一题不留
- **连续天数**每天打开就算一天，断一天从 1 重新开始

## 1.6 错题本

- 答错的题会自动进来（前提是这个内容上报了题目）
- 点开可以**看答案**，想明白了点"我想出来了"，它就变成已订正
- 订正过的题**再错一次会自动重新打开**，提醒你还没掌握

# 二、家长端（给家长用）

## 2.1 怎么进家长中心

家长端是**另一个地址**，孩子端里也没有明显的入口（怕孩子点进去）：

| 方式 | 怎么做 |
|---|---|
| **扫家长专属二维码** | `qr-parent-lan.png`，直达家长中心 |
| 输网址 | `http://<家里那台机器的地址>:8099/parent.html` |
| 从孩子端进 | 把孩子端滑到**最底部**，点"🔒 家长入口" |

> ⚠️ 家长端和孩子的入口长得像，别给孩子看到家长端的地址。

## 2.2 第一次要设密码

第一次打开会让你**设置**家长密码（两个输入框：设置密码 / 再输一次），**不是**输已有密码。

- 密码 4~6 位数字
- **每台设备各自独立** —— iPad 上设过一次，电脑上还要再设一次
- 连续输错 3 次会锁 60 秒；闲置 15 分钟自动锁回
- **忘记密码**：在那台设备的浏览器控制台执行
  `localStorage.removeItem('xyb.v1.guard')` 然后刷新，就能重设（**学习数据不受影响**）

## 2.3 家长端都有什么

| 区块 | 能干什么 |
|---|---|
| 📊 学习概览 | 今日时长 / 本周时长 / 已完成 / 正确率 / 错题待订正 / 连续天数 |
| 📋 学习明细 | 每个内容的完成度、时长、正确率、错题数、最近学习时间 |
| 📝 错题台账 | 全部 / 待订正 / 已订正 三个筛选；可标记、移除、一键清理已订正 |
| 📌 作业 | **录入老师原文**、看历史、重新解析 |
| 🗂️ 内容管理 | 把某个内容从孩子端**藏起来**，也可以放回来 |
| 👶 孩子档案与规则 | 昵称、头像、每日目标、休息间隔、护眼提醒开关、音效开关 |
| ☁️ 多端同步 | 让平板和电脑共用同一份记录（默认关闭） |
| 💾 数据备份 | 导出 / 导入 JSON、清空数据、修改密码 |

## 2.4 录入作业（最常用的功能）

### 步骤

1. 家长端 → **📌 作业**
2. 把老师在群里发的原文**整段复制**，粘进输入框
3. 点**解析**
4. 看**预览**：
   - 每一行的文字都可以**直接改**（解析不可能 100% 准，改一下就好）
   - 每行右边有"给家长"的开关 —— 打了勾的条目会进"要爸爸妈妈做的事"，
     孩子端看不到具体内容
   - 解析错的、多余的行可以**删掉**
5. 点**保存**

保存后孩子端刷新就能看到。

### 老师原文长什么样都行

程序会自己认出：

- `【数学】【语文】【班级通知】` 这类**板块标题**（只有在**行首**的才算标题）
- 四种序号写法：`1️⃣`、`①`、`1.`、`1：`
- 常见动词：读一读、背一背、说一说、想一想、写一写、做一做、练一练……
  并自动配一个小图标
- "自愿完成"这类字样会被**去掉**，孩子看到的更干净

### 为什么原文要留档

解析是"尽力而为"，老师的排版千奇百怪。所以**原文一直存着**：

- 随时可以对照原文检查解析对不对
- 以后程序升级了，点**重新解析**就能用新规则重跑 —— **已经打过的勾不会丢**

### 家长专属条目怎么处理

班级通知里的"疫苗""带书""在帽子上写姓名""私信老师"这类，**不是孩子的任务**。
给这些行打开"给家长"开关后：

- 它们出现在家长端的"👨‍👩‍👧 要爸爸妈妈做的事"
- 孩子端只显示一句"还有 N 件要提醒爸爸妈妈"，**不显示具体内容**
- 它们**不算进孩子的作业进度**（不完成也不影响"今天作业全做完"）

## 2.5 多端同步（可选，默认关闭）

**不开的时候**：每台设备各记各的，完全不联网。
**开的时候**：平板和电脑共用同一份记录。

### 怎么开

1. 家长端 → **☁️ 多端同步**
2. 地址填 `http://<家里那台机器的地址>:8100`
3. 设一个 4 位以上的**家庭口令**（不是家长密码，是同步专用的）
4. 点**连接并开启**
5. 第一台设备会问"以本机为准"还是"以云端为准" —— 第一次就选**以本机为准**

> 家庭口令在**每台设备上各输一次**，之后不用再输。

### 能做什么

- 看**连接状态**、**待发送条数**、**记录点（rev）**、**最后同步时间**
- 点**立即同步**手动推一次
- 看**历史版本**，任意时间点都能**回退**（比如误清空之后）
- 孩子端页脚有个只读的小胶囊显示同步状态，孩子看不到任何设置

### 断网会怎样

照常学习。事件会攒在本地，联网后自动补交，**不会重复计数**。

> ⚠️ 家庭口令在 HTTP 上明文传输，这是**家里内网**的方案，**不要把 8100 暴露到公网**。

# 三、常见问题

**Q：孩子端找不到"登录"在哪？**
孩子端**不需要登录**，打开就能用。要进家长端得用上面 §2.1 的三种方式之一。

**Q：孩子端滑到底才能看到"家长入口"，太隐蔽了。**
这是故意的（怕孩子点进去）。家长直接存 `qr-parent-lan.png` 那张二维码就行。

**Q：点按钮没反应？**
先刷新页面。如果还是没反应，把页面截图发给维护者 —— 现在所有失败都会在页面上显示原因，
**不再有"点了什么都不发生"的情况**。

**Q：拼音/发音没有声音。**

按这个顺序查（在拼音页点右上角 **🔊 声音自检**，它会直接告诉你卡在哪一步）：

1. 家长端"音效与语音"开关是不是关着
2. 设备**侧边的静音开关**（平板常见）是不是拨到了静音；音量调大；断开蓝牙音箱
3. 如果是老设备，可能是浏览器没有语音合成接口 —— 本项目已内置发音音频包，
   **正常情况下不依赖设备语音，任何浏览器都能响**
4. 还是不行，把自检面板截图发给维护者

**Q：在 iPad 上设了密码，电脑上怎么还要设？**
家长密码是**每台设备各存一份**的（不联网）。这是设计，不是 bug。

**Q：换设备后孩子的数据没了？**
默认数据只存在浏览器本地。三选一：

- 家长端 → 数据备份 → **导出**，在新设备**导入**
- 开启**多端同步**（推荐，之后自动同步）
- 从服务端的历史版本回退（前提是开过同步）

**Q：孩子说作业不对/少了？**
家长端 → 📌 作业 → 找到那一天 → 对照**老师原文**检查。
解析错了可以直接改行文字；程序升级后也可以点**重新解析**（打勾状态不会丢）。

**Q：孩子做了一半不想做了，会扣星星吗？**
不会。只有"完成"才加星。

**Q：清空浏览器数据会怎样？**
**学习记录会丢**。清之前先在家长端导出一次 JSON。清缓存/换浏览器都会触发这个问题。

**Q：能不能给孩子设"每天只能学 30 分钟"？**
目前只有**护眼提醒**（连续学习到设定时长弹提示），没有强制时长锁。
这个功能还在待决策列表里。

**Q：手机上能用吗？**
能。窄屏会自动切成底部 Tab 布局，触控区都做了放大。
