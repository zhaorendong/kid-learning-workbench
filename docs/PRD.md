## 0. 这份文档怎么用（先看这里）

这份 PRD 的目的不是"描述产品"，而是**每次迭代都能照着它验证功能是否还正常**。

每个功能条目固定带五样东西：

| 字段 | 含义 |
|---|---|
| **ID** | 稳定编号（A1、H4…）。提需求、报 bug、写变更记录都用它，不要改号，废弃就标 `已废弃` |
| **优先级** | P0 必须有 ／ P1 应该有 ／ P2 锦上添花 |
| **状态** | ✅ 已实现 ｜ 🔨 开发中/待开发 ｜ 💡 待决策 ｜ ❌ 明确不做 |
| **验收标准** | **可以观察、可以勾选**的一句话。做不到就不算完成 |

## 1. 背景与目标

**现状问题**：不同类型的知识内容（数独教程、口算练习、拼音、可打印题库……）散落成独立 HTML，
孩子找不到、家长看不到进度，每生成一份新内容都要重新告诉孩子"文件在哪"。

**目标**：

1. 孩子打开一个页面就能看到全部内容，点进去就能学，学完有反馈（星星、徽章）；
2. 家长能看到"学了多久、学到哪、哪里薄弱"，并能控制哪些内容出现；
3. **新内容生成后加一条注册记录就能出现在工作台**，不改框架代码；
4. **数据不丢、多端一致**：数据落到自建数据服务，前端崩溃/清缓存/换设备都能恢复，
   iPad 和电脑看到的是同一份进度；
5. **每天回家知道老师留了什么**，家长花一分钟把老师原文录进去，孩子自己看自己打勾。

**非目标（本期不做）**：

- 不做 AI 自动出题、不做付费内容、不做社交/排行榜
- 不做多租户/公有云，仅家庭自用（局域网 + VPN）

## 2. 用户与场景

| 角色 | 谁 | 用什么设备 | 关键诉求 |
|---|---|---|---|
| **孩子**（学习者，一年级） | 孩子 | iPad（主）/ 平板（备） | 打开就能学、有反馈、不用找文件；今天作业是什么 |
| **家长**（管理者） | 家长 | 电脑 / 手机 | 看进度、控内容、管时长、录作业、数据别丢 |
| **内容生产者**（本项目的特殊角色） | 家长 + AI | 电脑 | 生成一份新 HTML，3 分钟接入工作台 |

**核心场景**：

1. 放学回家，孩子拿 iPad 扫码打开 → 首页第一张卡就是"今天的作业，还有 3 项" → 打勾；
   往下是口算卡片 → 做几题 → 答错的题进错题本
2. 家长晚饭后打开电脑 → 家长端输密码 → 看今天学了 18 分钟、正确率 82% → 把某内容藏起来
3. 老师在群里发了作业 → 家长粘贴到"📌 作业" → 预览改两行 → 保存 → 孩子那边立刻能看到
4. 新做一份"识字小达人" → 跑一条命令注册 → 刷新工作台就能看到 → 孩子明天开始学

## 3. 名词表

| 名词 | 含义 |
|---|---|
| **内容 / 模块** | 一个独立的学习 HTML，位于 `modules/<id>/`（或历史目录），在 `catalog.js` 注册 |
| **注册表** | `assets/catalog.js`，全站唯一的内容目录 |
| **SDK** | `assets/xyb-sdk.js`，内容页引入一行即接入进度上报与朗读 |
| **inbox** | 模块是独立页面，无法直接调工作台函数；SDK 把事件写进 localStorage 队列，工作台回来时消费 |
| **会话结算** | 进模块写 `session`，回工作台算时长（<15 秒忽略、>4 小时视为挂机） |
| **错题本** | 跨模块聚合的错题集合，去重键 `mid\|q` |
| **作业板块** | 老师原文里的 `【数学】【语文】【班级通知】` 一级分组 |
| **事件 / rev** | 同步的最小单位。每次写入生成一条事件（含全局唯一 id），服务端按到达顺序分配递增 `rev` |
| **收敛** | 各设备拿"同一批事件"重算状态，结果必然一致 —— 服务端不做业务合并 |
| **gen** | 日志世代。回滚 = 截断日志 + `gen+1`，客户端发现 gen 变化就丢弃本地缓存全量重拉 |

## 5. 关键功能的验收细则

> 只列"光看清单勾不出来"的，其余见 §4 的验收标准列。

### 5.1 B4 学习时长结算

| 场景 | 期望 |
|---|---|
| 进模块 → 2 小时才回来 | **不计入**（视为挂机） |
| 进模块 → 10 秒就返回 | **不计入**（太小，可能是误点） |
| 进模块 → 8 分钟返回 | 计入 8 分钟；`visits +1`；写一条 `leave` 流水 |
| 直接用浏览器后退回到工作台 | 仍要结算（靠 `pageshow` + `persisted`） |
| 在模块里刷新了页面 | 不重复结算 |

### 5.2 B7 错题本入库规则

| 场景 | 期望 |
|---|---|
| `answer(false, '进位加法')` 无题干 | **不入库**（老模块不改也不会误记） |
| `answer(false, {q:'3+9=?', ...})` | 入库，`times=1` |
| 同一题再错 | `times+1`，不新增记录 |
| 已订正后又错 | `fixed` 归零（重新打开） |
| 超过 300 条 | 保留最近 300 条 |

### 5.3 C1/C2 星级与徽章边界

| 场景 | 期望 |
|---|---|
| 重复学完同一个内容 | 不再加星，不重复撒彩带 |
| 手动打勾撤销 | 扣回 3⭐，状态回到"学习中"，**徽章不撤销**（已获得即保留） |
| 连续天数 | 同一天多次打开只算 1；隔天 +1；断 2 天归 1 |

### 5.4 D1 门禁安全边界

| 场景 | 期望 |
|---|---|
| 未解锁 | `#app` 为 hide，**一个字节的数据都不渲染** |
| 连错 3 次 | 锁 60 秒，期间输入框与按钮 disabled |
| 锁定期间刷新页面 | 锁仍生效（状态在 localStorage） |
| **输入全角数字 `１２３４`** | **净化成半角后正常校验**（不能"点了没反应"） |
| **输入带空格 `' 1234 '`** | 去空格后正常校验 |
| 输入非法内容 | 页面**显示红色错误提示**，不放行 |
| 忘记密码 | 控制台 `localStorage.removeItem('xyb.v1.guard')` 后刷新可重设，**学习数据不受影响** |
| 家长端改密码 | 旧密码立即失效 |

> 如实告知：PIN 只挡"防孩子"级别，哈希在本机，**不防有心人**。家里自用足够。
>
> **反面教训（已修）**：输入框曾带 `pattern="[0-9]*"`，浏览器原生校验不通过时
> **`submit` 事件根本不派发**，自己的校验逻辑没机会跑 —— 用户看到的就是"点了没反应"。
> 现在已去掉 `pattern`/`required`，校验全在 JS 里做，并把错误显示出来。

### 5.5 F6 孩子端 / 家长端隔离红线

| 检查 | 期望 |
|---|---|
| 孩子端 HTML 是否含家长控件 | **19 个家长端 id 一个都不能有** |
| 孩子端是否加载 `parent.js` | 不能 |
| 孩子端是否保留唯一家长入口 | 页脚一个 `./parent.html` 链接 |
| 孩子端脚本引入 | 必须含 `core.js` + `sync.js` + `student.js` |

### 5.6 G5 多端收敛（最容易做错的地方）

| 场景 | 期望 |
|---|---|
| 两台设备同时各完成 1 个内容 | 两侧都显示 2 个已完成 |
| 同一事件重复提交 | 服务端按 id 去重，`times` 不重复累加 |
| **服务端已落盘但响应在回程丢了** | 客户端收到 `ackIds`（含重复件 id）后清空队列，**不永久重传** |
| 服务端回滚（gen+1） | 客户端发现 gen 不一致 → 丢弃本地事件缓存 → 全量重拉 |
| 服务端未升级、没有 `ackIds` 字段 | 客户端行为与旧版一致，不报错 |

### 5.7 H1 作业解析器（老师排版千奇百怪）

| 输入特征 | 期望 |
|---|---|
| 只有**行首**的 `【xx】` 才算板块标题 | 内容里的 `【六、八】` 不会切出假板块 |
| 序号认四种写法：`1️⃣ / ① / 1. / 1：` | `1️⃣说一说：…` 能被识别成一条任务 |
| 动词识别先看**开头 12 个字**，再全句兜底 | "找两样东西比一比，说一说谁多谁少"不会被判成"说一说" |
| 家长待办**都在班级通知板块里** | 按"班级通知"筛选而不是排除，否则永远为空 |
| "自愿 / 均为自愿完成" | 从孩子看到的任务文案里去掉 |

### 6.2 服务端（数据目录）

```
<数据目录>\
├── state.json              权威全量状态（原子写：temp + rename）
├── versions\               每次写入前的快照，保留最近 N 份
│   └── 20260914-163012.json
└── meta.json               设备列表、最后写入时间、版本计数、口令哈希
```

**关键设计约束**：服务端是**权威副本**，浏览器 localStorage 是**离线缓存 + 待发送队列**；
服务端**不做业务合并**，只追加与去重 —— 各端拿到同一批事件后重算，结果必然一致。
