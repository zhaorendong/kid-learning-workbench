# 小学生学习工作台 · 需求评审稿

> 版本 v0.2 ｜ 2026-09-14 ｜ 评审人：家长（家庭自用项目）
> 配套代码：`index.html`（孩子端）+ `parent.html`（家长端）+ `assets/` + `modules/`

## 一、要解决什么问题

**现状**：不同类型的知识内容（数独教程、口算练习、古诗朗读、可打印题库……）目前是散落的独立 HTML / 文件，
孩子找不到、家长看不到进度，每生成一份新内容都要重新告诉孩子"文件在哪"。

**目标**：建一个**统一入口**，让：

1. 孩子打开一个页面就能看到全部内容，点进去就能学，学完有反馈（星星、徽章）；
2. 家长能看到"学了多久、学到哪、哪里薄弱"，并能控制哪些内容出现；
3. **新内容生成好后，加一条注册记录就能出现在工作台里**，不需要改动框架代码。

**非目标（本期不做）**：

- 不做账号体系、不做云端同步、不做付费内容
- 不做 AI 自动出题（后续按需单独立项）
- 不做社交/排行榜（涉及隐私与攀比风险，见评审问题 Q4）

## 二、参考平台对标：我们借鉴什么

调研了国内外 9 个主流儿童学习产品，提取可复用的机制：

| 平台 | 核心亮点 | 我们借鉴的部分 |
|---|---|---|
| **ABCmouse** | 可见的 Step-by-Step Learning Path 地图 + 票券兑换虚拟物品 + 多子档案 | 学习路径可视化、路径进度条；**暂不借鉴**虚拟商城（易跑偏成消费驱动） |
| **IXL** | 出题级记录 → SmartScore 自适应 → 家长端精细报告（时长/正确率/薄弱点/成长曲线） | 家长端数据维度（本框架已实现"时长+完成度+正确率"三件套） |
| **Khan Academy Kids** | 完全免费、无广告、角色化叙事、语气温柔不施压 | 反馈文案基调"答错不批评"，不搞扣分惩罚 |
| **Prodigy** | RPG 冒险外壳包裹自适应练习 | 学习路径用"闯关"叙事包装（框架已用 🗺️ 路径条呈现） |
| **Epic!** | 图书馆式自由选读 + 作业指派 + 完成度上报 | "自由探索"与"家长指定"两条并存的内容获取方式 |
| **Duolingo ABC** | 极短课时（3-5 分钟）、音频+描红+拼词的强交互 | 每个内容标注预计时长，鼓励"每天十几分钟" |
| **小步智学** | 8 题测评定位漏洞 → 每日轻量任务；艾宾浩斯复习；错题按类型分类；积分可兑换（家长自定义规则） | 错题本雏形、"每日目标"概念（已实现）、家长自定义规则 |
| **一起学** | 学情诊断报告、自动错题本+同类题推送、课本点读跟读、听写自测、护眼提醒+时长管控、多设备同步 | 护眼提醒（已实现）、时长管控（待决策 Q9）、按内容维度汇总的报告表（已实现） |
| **小学生学习帮** | 闯关星星奖励、专项训练模块（口算/拼音/单词）、错题本按科目筛选一键重做 | 专项训练作为独立模块的组织方式；星星奖励（已实现） |

**结论**：孩子端要做"路径 + 卡片 + 即时反馈 + 轻奖励"，家长端要做"数据说得清 + 能管控"，系统层要做"接入零成本"。

## 四、本轮已交付（v0.2）

### 1）孩子端与家长端拆成两个独立页面

| | 文件 | 内容 |
|---|---|---|
| 孩子端 | `index.html` | 首页 / 全部课程 / **错题本** / 我的成就（顶部导航 + 底部 Tab 各 4 项） |
| 家长端 | `parent.html` | 学习概览 / 学习明细 / 错题本 / 内容管理 / 孩子档案与规则 / 家长密码 / 数据备份 |

**隔离做法**（对应原 Q6）：

- 孩子端**不含任何家长控件**（无 `#pTable`、`#setName`、导出按钮…），也不加载 `parent.js`
- 孩子端只在页脚留一个"🔒 家长入口"链接，点进去是密码页，看不到任何数据
- 家长端 4~6 位数字密码，哈希后存本机；**错 3 次锁 60 秒**；闲置 15 分钟自动锁回
- 忘记密码的出路是控制台执行 `localStorage.removeItem('xyb.v1.guard')`，没有留后门
- 两端共用 `assets/core.js` 数据层，所以数据天然互通，不需要任何同步机制

### 2）错题本（原 B7，跨模块聚合）

```
模块 answer(false, { tag, q, answer, my })  →  xyb.v1.inbox  →  工作台入库 xyb.v1.mistakes
                                                                    ↓
                                            孩子端「🔁 错题本」订正    家长端错题台账
```

- 只有带题干的答错才入库，**老模块不改也不会误记**
- 同一道题再错只累加次数，不重复占位；订正后又错会自动重新打开
- 孩子端：题目卡 + "看看答案" + "我想出来了"（打勾出本子）
- 家长端：按 全部/待订正/已订正 筛选，可标记、可移除、可一键清理已订正的
- 新增 2 个徽章：🔁 错题克星、🧹 一题不留

### 3）新接入内容

- 🅿️ **拼音王国**（新增）：23 个声母点读墙 + 听音辨声母 + 拼读成音节，10 题一轮
  - 发音用浏览器自带语音合成读**示例汉字**（读"爸爸"而不是读"b"），离线可用
- ⚡ **口算闪电侠**（升级）：答题上报改为带题干，错题自动进错题本
- 🔢 **数独闯关营**：原位保留未改动，手动打勾模式
- 规划中占位 5 个：识字小达人、单词卡片盒、古诗小剧场、科学小实验、图形规律屋

### 4）工具链

- `xyb-sdk.js` 新增 `answer(correct, {tag,q,answer,my})`、`speak()`、`canSpeak()`
- `check_refs.py` 升级为**双页面检查**，新增"孩子端不得含家长端控件"的隔离红线检查
- `smoke_test.js` 覆盖两端：**125 条用例全部通过**，含门禁设密码/输错/锁定/改密码全流程

**验证结果**：`new_module.py --check` 8 条正常（3 上线 / 5 规划）；`check_refs.py` 全绿；
`smoke_test.js` 125/125 通过、两端全流程零 JS 错误。

## 五、待决策问题（评审重点）

> 每条都给选项 + 我的建议，评审时逐条拍板即可。

**Q1 主设备与入口形态**
- (a) iPad 为主，PWA 添加到主屏，孩子自己点开
- (b) PC 浏览器为主，家长在旁边陪着
- (c) 局域网部署到 部署机，多设备都能访问 ← **建议**：先 (a) 单机跑通，再补 (c) 局域网
- 影响：PWA 图标、触控尺寸、单双列布局

**Q2 内容组织的主轴**
- (a) 按学科（语文/数学/英语…）
- (b) 按学习路径（数感与计算 → 逻辑思维 → 阅读积累）
- (c) 混合：首页给路径，全部课程页给学科 ← **当前实现是 (c)，建议保留**
- 影响：首页信息架构、内容卡片排序逻辑

**Q3 是否需要多孩子档案**
- (a) 不需要，就小悦饼一个人用 ← **建议**
- (b) 需要，预留第二个档案入口（数据结构已兼容，成本低）
- 影响：数据模型是否要加一层 profile 维度

**Q4 激励体系做到什么程度**
- (a) 星星 + 徽章 + 连续天数（**当前已实现，建议先跑一段时间看效果**）
- (b) 加积分商城，家长自定义兑换规则（如 50 分换一次公园）
- (c) 加宠物养成 / 家园装扮
- (d) 排行榜 —— **建议不做**，容易变成跟别人比而不是跟自己比
- 影响：开发量、是否会把学习动机带偏

**Q5 是否要"复习"机制**
- (a) 不做，孩子自由选内容
- (b) 轻量：错题自动进错题本，家长端可见
- (c) 完整：艾宾浩斯排期，到期知识点自动进"今日任务" ← **建议先 (b)，有效再加 (c)**
- 影响：是否需要"知识点"层级的数据结构

**Q6 家长端是否需要加锁（PIN）**
- (a) 不加，同一页面切换即可 ← **建议**（家里自用，加锁反而麻烦）
- (b) 加 4 位 PIN，防止孩子乱改设置
- 影响：家长端入口交互

**Q7 新内容如何出现在工作台**
- (a) 跑脚手架脚本注册（**当前实现**，一条命令）
- (b) 手工在 `catalog.js` 里加一条
- (c) 自动扫描 `modules/` 目录 —— 纯静态页做不到目录列举，需要构建步骤或 SW，**不建议**
- 影响：内容生产的工作量

**Q8 模块打开方式**
- (a) 整页跳转，模块全屏沉浸，返回键回工作台（**当前实现**）
- (b) iframe 内嵌，始终保留工作台导航栏
- (c) 混合：讲解类 embedding、游戏类跳转
- 影响：是否统一"返回工作台"体验（当前 SDK 已能注入悬浮返回按钮）

**Q9 是否要做时长管控 / 超时锁屏**
- (a) 只做护眼提醒（**当前实现**）
- (b) 加"每日总时长上限"，超时锁定并提示
- 影响：家长控制力度

**Q10 下一批内容优先做哪些**
- 候选：口算已有 → 拼音王国 / 识字小达人 / 单词卡片盒 / 古诗小剧场 / 图形规律屋 / 科学小实验
- 建议：先做 **拼音** 或 **口算进阶（100 以内）**，因为一年级校内刚需、复用现成交互模式快

## 七、技术说明（供评审时理解成本）

```
小悦饼知识库/
├── index.html                    ← 孩子端入口（双击即用）
├── parent.html                   ← 家长端（PIN 门禁）
├── manifest.webmanifest          ← PWA，可添加到 iPad 主屏
├── assets/
│   ├── app.css                   ← 统一设计令牌（配色/圆角/字号），两端共用
│   ├── core.js                   ← 数据层 + 业务逻辑 + 错题本（两端共用）
│   ├── student.js                ← 孩子端界面
│   ├── parent.js                 ← 家长端界面 + 门禁
│   ├── catalog.js                ← ★ 内容注册表（唯一需要维护的目录文件）
│   ├── xyb-sdk.js                ← ★ 内容接入 SDK
│   └── icon.svg
├── modules/
│   ├── _template/                ← 新内容模板（复制即开工）
│   ├── math-calc/                ← 口算闪电侠
│   └── pinyin-1/                 ← 拼音王国
├── 一年级数独/                    ← 已有产物，原位保留未改动
├── _build/
│   ├── new_module.py             ← 脚手架：建模块 / 注册 / 体检
│   ├── check_refs.py             ← 引用一致性 + 页面隔离检查
│   └── smoke_test.js             ← jsdom 真实 DOM 冒烟测试（两端）
└── docs/
    ├── 需求评审.md                ← 本文件
    ├── 模块接入规范.md            ← 生成新内容时遵循的规范
    └── 运维手册.md              ← 局域网访问（iPad / 手机）
```

**数据存在哪**：浏览器 `localStorage`，命名空间 `xyb.v1.*`，完全本地、不联网、不上传。
导出为 JSON 即可备份/迁移（含错题本）。

**新增一个内容要三步**（约 3 分钟）：
1. `python _build/new_module.py --id hanzi-1 --title "识字小达人" --subject 语文 --type practice`
2. 编辑 `modules/hanzi-1/index.html` 填充内容（照抄拼音王国的骨架最快）
3. 刷新工作台 → 内容已出现，学完自动记星星、错题自动进错题本

**改完框架必须跑的三条验证**（语法检查查不出"事件绑定失效"）：
```
python _build/new_module.py --check     # 注册表 ↔ 文件一致性
python _build/check_refs.py             # 引用一致性 + 孩子端/家长端隔离
node _build/smoke_test.js               # 真实 DOM 冒烟（需设 NODE_PATH 指向 jsdom）
```

**风险提示**：
- 数据在浏览器本地，**清理浏览器数据会丢失** → 已提供导出功能，建议家长每周导出一次
- `file://` 直接打开时，少数浏览器对跨目录 localStorage 有隔离策略（模块在 `modules/` 子目录），
  若发现进度不记录，改用本地 HTTP 服务（部署机 nginx 方案，见 `docs/运维手册.md`）即可解决
- 家长密码只是"防孩子"级别的隔离，密码哈希存在本机，**不防有心人** —— 家里自用足够
